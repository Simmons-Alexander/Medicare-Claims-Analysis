# Medicare-Claims-Analysis
Analysis of synthetic Medicare inpatient claims using SQL (BigQuery), Power BI, and Python (Pandas). Since the data is synthetic, results show method and are not real-world findings.

Files: two write-ups (PDF), SQL for data exploration and a HEDIS-inspired readmission measure, a pandas notebook, and the Power BI dashboard. Open the .pbix in Power BI Desktop; Simmons_Medicare_Claims_Dashboard_Preview.png is a preview.
